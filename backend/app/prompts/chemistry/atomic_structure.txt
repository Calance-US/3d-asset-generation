## 🧩 Scene Composition

Include the following components arranged in a realistic 3D configuration:

* A **nucleus** represented by a cluster of protons and neutrons (spheres with distinct colors) arranged together in a **spherical arrangement** rather than cubic.  
To achieve a natural spherical clustering of nucleons inside the nucleus, generate positions for protons and neutrons using a spherical distribution based on the golden ratio, with a bit of randomness to simulate a natural look. For example:

```js
  const radius = Math.cbrt(total) * 0.8; // Base radius on cube root of total particles
  const positions = [];

  // Generate positions using spherical distribution
  for(let i = 0; i < total; i++) {
    // Use golden ratio for better spherical distribution
    const phi = Math.acos(1 - 2 * (i + 0.5) / total);
    const theta = Math.PI * (1 + Math.sqrt(5)) * (i + 0.5);
    
    // Add some randomness to make it look more natural
    const jitter = 0.2;
    const r = radius * (0.8 + Math.random() * jitter);
    
    positions.push(new THREE.Vector3(
      r * Math.sin(phi) * Math.cos(theta),
      r * Math.sin(phi) * Math.sin(theta),
      r * Math.cos(phi)
    ));
  }
````
